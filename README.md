# Christoffel's

## Overview
This is a React Native mobile application developed for the MAST5112 Portfolio of Evidence (Part 2). The application provides a digital platform that allows kitchen staff and chefs to easily organize, update, and manage their daily menu offerings directly from their phones, replacing disorganized paper systems.

## Current Features (Part 2 Version)
*   **Menu Dashboard:** A primary list view that automatically updates to display all current menu items.
*   **Add Item Screen:** A dedicated data entry screen to capture new dishes.
*   **Data Capture:** Records the Dish Name, Description, Course (using a dropdown picker for Starter, Main, or Dessert), and Price.
*   **Input Validation:** Ensures no required fields are left blank and restricts the price field to numeric input.
*   **User Feedback:** Displays error messages for incomplete forms and provides a success confirmation when an item is saved.

## Technologies Used
*   React Native
*   Expo
*   `@react-native-picker/picker`
